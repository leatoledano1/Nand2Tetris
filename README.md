# Nand2Tetris — Building a Computer from First Principles
A collection of projects from Nand2Tetris (From NAND to Tetris), as taught at the Hebrew University of Jerusalem.

The course explores how a computer works by building its layers from the ground up: Boolean logic gates, arithmetic
circuits, memory, a CPU, machine language and software translation tools. Each project builds on the ideas introduced 
in earlier projects, connecting hardware design with low-level and high-level programming.
